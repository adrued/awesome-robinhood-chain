# Contributing to Awesome Robinhood Chain

Thank you for contributing! We welcome additions and updates that help the Robinhood Chain ecosystem grow.

## Contribution Guidelines

1. **Factual & Objective:** Keep descriptions neutral, factual, and concise (one sentence).
2. **Maturity Tags:** Every entry must include an accurate maturity tag:
   - `[live]` – In production and accessible to users on Robinhood Chain mainnet.
   - `[beta]` – Publicly accessible but in early or testing phase.
   - `[experimental]` – Early prototype, active development, or research.
3. **Entry Format:** Follow the standard Awesome List format:
   ```markdown
   - `[tag]` **[Project Name](https://link)** — One-line description of what it does.
   ```
4. **Category Selection:** Place your entry under the most appropriate category heading. If a new category is needed, please explain why in your PR.
5. **Relevance:** Ensure the project directly supports, integrates with, or deploys on Robinhood Chain.

## Pull Request Process

1. Fork the repository and create a new feature branch.
2. Edit `README.md` to add your entry within the relevant section.
3. Submit a Pull Request with a clear title and description explaining the project and its maturity status.
